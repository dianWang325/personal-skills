# Personal skills

个人 Codex skills。实验数据和日志保存在独立本地仓库 `D:\experiment`，不存入本仓库。

## 已有 skill

- [experiment-record](skills/experiment-record/SKILL.md)：从日志归档实验、检索历史、按时间复盘。

## 安装 / 更新

将需要的 `skills/<name>` 整个目录复制到 `$CODEX_HOME/skills/<name>`（未设置时为 `~/.codex/skills/<name>`）。修改以本仓库为源，更新后重新复制整个 skill 包；不要直接把实验日志放入 skill 目录。新会话可用 `$experiment-record` 调用。

Windows 本机安装位置：`C:\Users\w00985415\.codex\skills\experiment-record`。

仓库仅管理本人编写或明确授权迁入的 skills，现有其他 skills 未自动复制。
